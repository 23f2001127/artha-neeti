# assets

Source files shared by the backend and the documentation.

| Path | Contents |
| --- | --- |
| `brand/logo.png` | The master logo; every other logo file is generated from it |
| `brand/mark.png`, `brand/wordmark.png`, `brand/lockup.png` | Transparent crops generated by `scripts/build_brand_assets.py`. `mark.png` and `wordmark.png` are used by the PDF export; `lockup.png` by the README. |
| `fonts/` | Inter (Regular, SemiBold, Bold) and Source Serif 4 SemiBold, embedded in PDF reports |

Both font families are licensed under the SIL Open Font License 1.1; the
license texts are in `fonts/OFL-Inter.txt` and `fonts/OFL-SourceSerif4.txt`.

Web icons and images live in `frontend/public/brand/` and are generated by the
same script.
